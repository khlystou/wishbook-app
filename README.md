# Мастер желаний

Редактор чековых книжек с предпросмотром и печатью. Черновики хранятся в браузере.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000.

## Деплой в Laravel Forge

Создайте сайт типа Static HTML, подключите репозиторий и укажите Web Directory /out. Установите Node.js 22.13 или новее на сервере.

В скрипте стандартного деплоя сохраните команды Forge, которые переходят в папку сайта и обновляют репозиторий. Затем добавьте:

```bash
npm ci
npm run build
test -f out/index.html
```

Для деплоя без простоя выполните эти команды в каталоге нового релиза до его активации. Nginx раздаёт готовые файлы из out. Постоянный процесс Node.js и база данных не нужны.
